# INTUBE Premium 💎 - Short Video App

> TikTok / Insta Reels jaisa Premium Short Video Platform - Made in India 🇮🇳

### 🔥 Live Project
**Repo:** `sg7212702-star/intube-android`
**Tech:** Kotlin + Jetpack Compose + Firebase + Cloudinary

### ✨ Features
- 📱 **Reels Feed** - Infinite scroll, auto-play, double-tap like
- ❤️ **Like / Comment / Follow** - Real-time Firebase
- ☁️ **Cloudinary Upload** - Free video/image upload
- 🔔 **Notifications** - Like, Comment, Follow alerts
- 👤 **Profile** - My videos, Followers, Following
- 🔐 **Google Login** - Secure Firebase Auth
- 🎨 **Premium UI** - Neon gradient, dark theme

### 🛠️ Tech Stack
- **Android:** Kotlin, Jetpack Compose, MVVM
- **Backend:** Firebase (Auth, Firestore, Storage)
- **Media:** Cloudinary (free CDN)
- **Build:** Gradle Kotlin DSL

### 🚀 Setup
1. Clone: `git clone https://github.com/sg7212702-star/intube-android.git`
2. Open in Android Studio
3. Add `google-services.json` in `/app`
4. Run!
